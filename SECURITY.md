# Security Policy

## Reporting a vulnerability

**Please do not report security issues in public issues, discussions or pull
requests.**

Report them privately through GitHub Security Advisories:
**[Report a vulnerability](https://github.com/spellcache/spellcache/security/advisories/new)**
(repository → *Security* tab → *Report a vulnerability*).

Please include:

- the affected version or commit;
- a description of the issue and its impact;
- the steps to reproduce it, or a proof of concept;
- any idea of a fix, if you have one.

## What to expect

- An acknowledgement within a few days.
- A first assessment and, if confirmed, a plan and an estimated timeline.
- A fix released as a new version, then a published advisory crediting you
  (unless you prefer to stay anonymous).

Please give us a reasonable time to release a fix before any public disclosure.

## Supported versions

Only the latest release receives security fixes. Self-hosted instances should
update to it (see the self-hosting guide, *Updating*).

## Scope

In scope: the spellcache application and its official Docker images.
Out of scope: vulnerabilities in third-party services (Scryfall, Resend, GitHub)
and issues that require an already compromised server or administrator account.
