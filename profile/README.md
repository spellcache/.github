# spellcache

**Your Magic: The Gathering collection, on your own server.**

spellcache is an open-source, self-hosted web app to manage a card collection:
inventory, binders, deck building, collection value and table tools. Mobile
first, installable as an app, and built to run on a small server or a
Raspberry Pi.

- 📦 **[spellcache/spellcache](https://github.com/spellcache/spellcache)** — the
  app: source code, issues and releases
